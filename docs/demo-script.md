# Guion de demo de RIMPILOT

1. Marca el número de Twilio configurado.
2. Dile a Wari: “Vendí tres pollos a veinticinco soles cada uno, me pagaron por Yape. Gasté quince en pasaje y a Doña Rosa le fié veinte.”
3. Wari confirma los tres movimientos y lee el resumen: ventas S/ 75, gastos S/ 15, saldo S/ 60 y S/ 20 por cobrar.
4. Muestra el dashboard: los movimientos aparecen sin recargar, incluido el texto que originó cada uno.
